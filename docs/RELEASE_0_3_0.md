# v0.3.0: Preserve Capabilities, Account for the Whole Experiment

Idea, research guidance, and product management: Sulabh Dubey.
Engineering, testing, and research synthesis: Codex under that direction.

## Added

- Project model/role restrictions and declared host capability checks.
- Upper token estimates and retry allowances in whole-workflow plans.
- Explicit image attachments for authorized read-only Codex CLI calls.
- Evidence snapshot/expiry and ordered source-line metadata.
- Expiring leases that retain unknown spend; ambiguous I/O cannot refund a call.
- Conservative matched-outcome calibration through CLI and MCP.
- Prompt-free, read-only local HTML budget dashboard with responsive QA.
- Reproducible multimodal pilot, retained failures, corrected planning trials,
  and offline receipt regrading tests.

## Evidence

The new pilot tested 24 batched questions across six families, with real chart
attachments, four workflows, and two rounds. All corrected final outputs passed.
A conflicting planning prompt was discovered and corrected; original receipts
and rerun costs remain published. Sixteen unique calls cost 51.43389 projected
credits. Sol was still cheaper than the corrected Astra routes.

See [results](https://github.com/sulabhdubey/premium-model-budget-governor/blob/main/docs/BENCHMARK_RESULTS.md)
and [controls](https://github.com/sulabhdubey/premium-model-budget-governor/blob/main/docs/CAPABILITY_CONTROLS.md).

## Scope

This remains an alpha with bounded evidence, not a perfect or universally optimal
router. Twenty-four questions are not twenty-four independent enterprise tasks.
No automatic learned-policy promotion, desktop pre-model enforcement, served-model
attestation, or guaranteed weekly savings is claimed. All license terms remain
Apache-2.0; this is an independent project, not an OpenAI endorsement.
