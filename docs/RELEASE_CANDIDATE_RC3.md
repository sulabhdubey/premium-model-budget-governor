# Workbench Candidate: 0.4.0rc3

Status: local preparation, not yet published. This is a testing candidate, not
completion of the product goal or a declaration of universal savings.

## Included

- Local direct-execution workbench: Astra Preferred or explicit Economy, project
  and evidence selection, actual images, host-supported reasoning, cost preview,
  approval, progress, cancellation, reconnection and receipts.
- Isolated installation and uninstall; setup diagnostics with a constrained
  downloadable report. No automatic login, hook trust or client configuration.
- Persistent reservations and terminal usage recovery; incomplete usage remains
  unknown and may block further execution. No provider billing cap is claimed.
- Reviewed routing preferences with explicit activation and rollback, not trained
  model weights or automatic policy promotion. No policy has been promoted from
  the currently insufficient real-task evidence.
- Authenticated loopback service, bounded input handling, private session files,
  evidence integrity checks and supplementary secret/injection pattern scans.
- Experiment reports that keep billed and projected credit summaries separate,
  optional whole-workflow timing, and a five-task authored starter suite.

## Important Limits

Execution uses a read-only filesystem sandbox. Inherited connector permissions
are not revoked. Prepared/review workflows remain separate planning/CLI paths;
the UI does not yet execute every workflow or support Desktop-only tools and edits.
The public landing demo is illustrative, not connected to the user's account.

Token counts come from available host receipts. Credits derived from those counts
are estimates. Weekly allowance attribution, serving-model attestation and hard
in-flight spending enforcement are unavailable. Unknown spending is never free.

Automated tests do not prove Astra-quality savings or unaided nontechnical use.
Independent RTA-Net/CircuitProof experiments, broader matched tasks, volunteer
onboarding, independent security review and remaining capability work stay open.
The five authored starter tasks do not substitute for these gates.
