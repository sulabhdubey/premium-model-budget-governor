# Open-Core Roadmap

The safety-critical base should stay free. Users should not have to pay to avoid
accidental premium-model waste or unsafe capsule creation.

## Free Core

- deterministic routing policy
- Sol-parity estimator
- secret scanning
- prompt-injection scanning
- evidence capsule builder
- capsule quality score
- evidence graph compiler
- shadow review packet builder
- cheap-model tournament ranking
- prompt-free telemetry normalization
- CLI
- MCP server
- Codex plugin bundle
- public synthetic eval
- public docs and examples

## Possible Pro Pack

These features can become paid without locking away core safety:

- visual budget dashboard
- team profiles and shared policies
- actual provider token telemetry adapters
- advanced benefit predictor calibration
- richer evidence graph visualization
- one-click sanitized case-study exporter
- hosted docs/demo site templates
- organization policy packs
- private support workflows

## Pricing Hypothesis

A one-time $10-$20 indie license can work if the paid value is convenience,
team workflow, and visibility rather than safety. For teams, a small per-seat or
per-workspace license may be easier to support.

## License Boundary

Keep the repo Apache-2.0 unless there is a clear reason to re-license. Apache-2.0
is familiar to companies and includes a patent grant, which makes adoption easier
than a custom license.

## Do Not Put Behind A Paywall

- secret scanning
- prompt-injection scanning
- basic routing
- CLI usage
- MCP server
- reproducible evals

Those are trust features. Trust should be part of the public surface.
