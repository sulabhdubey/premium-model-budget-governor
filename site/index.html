02 / How it works

Four moves. One governed loop.

  1. 01

    Explore

    Efficient models read broadly, test ideas, edit files, and inspect logs.

  2. 02

    Compress

    Rank evidence, scan secrets and injection, then score a bounded capsule.

  3. 03

    Judge

    A premium model receives one exact decision question, not the whole repo.

  4. 04

    Learn

    Prompt-free telemetry records whether premium judgment changed the outcome.

03 / Proof

The best premium call is sometimes the one you withhold.

Two sanitized local project tests at roughly 12% weekly capacity produced the same honest result: use Sol now, preserve Astra for an unresolved decision.

Architecture review 0 Astra turns

Existing invariants resolved the decision. The capsule was correctly withheld.

Release security review 76% avoided overhead

Shadow Mode after Sol would have cost more than Sol-only for the current evidence state.

04 / Included

A complete control layer.

CLI, Python library, MCP server, and a ready Codex plugin.

  • 01
    Deterministic router

    Allow, block, request approval, or route to a cheaper model.

  • 02
    Sol-parity estimator

    Keep premium billable token volume inside a comparable budget.

  • 03
    Context Poison Firewall

    Scan untrusted evidence for secrets and prompt-injection patterns.

  • 04
    Capsules and evidence graphs

    Give frontier models compact claims, files, tests, risks, and decisions.

  • 05
    Shadow Mode and tournaments

    Use premium intelligence as the judge over efficient model work.

  • 06
    Learning ledger

    Calibrate future routing from outcomes without storing raw prompts.
